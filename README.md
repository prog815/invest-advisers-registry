# 📁 Интерактивный справочник инвестиционных советников

Онлайн-справочник по Единому реестру инвестиционных советников Банка России. Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/invest-advisers-registry/](https://prog815.github.io/invest-advisers-registry/)

Этот справочник — для инвесторов, юристов, комплаенс-специалистов, аналитиков финансового рынка и сотрудников служб безопасности. Главная задача — помочь быстро проверить, внесён ли инвестиционный советник — компания или ИП — в реестр Банка России и **совпадает ли сайт, на котором предлагают инвестиционные рекомендации, с адресом, указанным в реестре**.

---

## Что кодирует реестр инвестиционных советников

**Единый реестр инвестиционных советников** — официальный перечень профессиональных участников рынка ценных бумаг, имеющих право оказывать услуги по инвестиционному консультированию. Он отвечает на вопросы: **«Вправе ли этот советник давать инвестиционные рекомендации?»**, **«Совпадает ли его сайт с указанным в реестре?»** и **«Не исключён ли он из реестра?»**.

В текущем снимке справочника содержится **284 записи**, из которых:
- **153 действующих** советника (87 организаций и 66 индивидуальных предпринимателей);
- **131 исключённый** из реестра (46 организаций и 85 предпринимателей).

Структура реестра **плоская** — один советник, одна запись. Карточка содержит:
- ОГРН (для организаций) или ОГРНИП (для ИП) — используется как уникальный идентификатор. У нескольких исключённых предпринимателей ОГРНИП в выгрузке не указан — для них идентификатором служит ИНН;
- ИНН;
- Полное наименование организации или ФИО предпринимателя, сокращённое наименование (для организаций);
- Адрес (для организаций);
- **Официальные сайты** (полные URL) и нормализованные **домены** (для поиска);
- Контактные телефоны и электронную почту;
- Дату внесения в реестр и **дату исключения** (для исключённых).

> **Важно про другие финансовые организации.** Инвестиционный советник даёт индивидуальные рекомендации, но не проводит сделки и не управляет активами — для этого нужны брокер или управляющая компания (отдельные реестры Банка России). Если вам нужно проверить МФО, ломбард, страховую компанию или паевой инвестиционный фонд, используйте соответствующие справочники экосистемы.

## Для кого и зачем

Справочник пригодится, если вам нужно:
- **проверить советника перед оплатой рекомендаций** — убедиться, что компания или предприниматель легальны, особенно если услуги предлагают в рекламе, мессенджерах или соцсетях;
- отличить настоящий сайт советника от мошеннического сайта-двойника;
- узнать, действует ли советник сейчас или уже исключён из реестра (с указанием точной даты исключения);
- найти ИНН или ОГРН/ОГРНИП для сверки договора инвестиционного консультирования и документов;
- отфильтровать рынок по типу (организации / предприниматели) и статусу.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Поиск по реквизитам и домену.** Введите название, ФИО, ИНН, ОГРН/ОГРНИП, адрес сайта, телефон или email. **Поиск по домену — главная фича**, и здесь он устроен строже, чем в других справочниках: домен сравнивается **целиком**, поэтому `advisor.ru` не совпадёт с `advisor.ru.example.com`. Это защищает от ложных совпадений при проверке ссылок из рекламы и мессенджеров.
- **Поиск по ссылке целиком.** Можно вставить полный адрес страницы, например `https://sroamiks.ru/shomin/`, — поиск найдёт конкретного советника. Это важно для общих доменов: часть предпринимателей размещает страницы на сайте своей саморегулируемой организации, и на домене `sroamiks.ru` живут страницы 35 советников — различаются они именно путём.
- **Два фильтра.** Выпадающие списки по **Типу** (ЮЛ — организации / ИП — предприниматели) и **Статусу** (Действующий / Исключён). По умолчанию показываются только действующие.
- **Копирование в один клик.** Клик по бейджу с ОГРН, ОГРНИП или ИНН копирует номер в буфер обмена. Внизу экрана появится подтверждение.
- **Бейджи статуса и дата исключения.** Цветной бейдж показывает, действует ли советник. У исключённых выводится **красный блок с точной датой исключения** из реестра.
- **Прямые ссылки на сайты.** Клик по чипу с URL сайта открывает его в новой вкладке.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` формирует полный текст с реквизитами советника и ссылкой на карточку.
- **Прямые ссылки на карточки.** Каждого советника можно передать через `?code=…` в адресе (по ОГРН/ОГРНИП, для записей без ОГРНИП — по ИНН). Если советник исключался и был включён в реестр повторно, ссылка покажет **обе записи** — полную историю.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в тексте карточки.

## Примеры запросов

- `АЛОР` — найдёт карточку ООО "АЛОР +".
- `1027700075941` — откроет карточку компании по её ОГРН.
- `alorbroker.ru` — найдёт компанию по домену сайта (главная фича).
- `https://sroamiks.ru/shomin/` — найдёт конкретного предпринимателя по странице на общем домене СРО.
- `010106751003` — найдёт советника по ИНН с ведущим нулём.
- `gazprombank.investments` — найдёт ООО «Ньютон Инвестиции» по одному из двух его сайтов.
- `info@bcs.ru` — найдёт компанию по адресу электронной почты.
- `21.12.2018` — найдёт всех советников, внесённых в первый день работы реестра.

**Популярные фильтры:**
- **Действующий** — советники, имеющие право оказывать услуги инвестиционного консультирования (153 записи);
- **Исключён** — исключённые из реестра, с точной датой исключения (131 запись);
- **ЮЛ / ИП** — организации или предприниматели, в сочетании с любым статусом.

У всех 153 действующих советников в реестре указан официальный сайт — проверка по домену работает для каждого.
